# EditorsHub — install

## Download

**https://github.com/official-hub-000/EditorsHub/releases/download/android-latest/editorshub-debug.apk**

That link always points at the newest build. The file is `editorshub-debug.apk`, about 12 MB.

## Install on your phone

1. Tap the link above on your phone (not on a computer).
2. Your browser asks whether to download the file — allow it.
3. When it finishes, open it from the notification, or from **Files → Downloads**.
4. Android warns that the app is from an unknown source. Tap **Settings** in that warning
   and allow your browser to install apps. This is normal for any app that is not from the
   Play Store.
5. Tap **Install**, then **Open**.

The app appears on your home screen as **EditorsHub**.

## If it will not install

- **"App not installed"** — an older copy is already on the phone with a different signature.
  Uninstall the old EditorsHub first, then install again.
- **Play Protect blocks it** — tap **More details**, then **Install anyway**. Play Protect
  flags any app it has not seen before.

## Updates

Open the same link again to get the newer file and install it over the old one. Your
projects stay on the phone.

## What is inside

- Fully English interface, no language switch.
- One credit: Official Hub.
- Works offline — the editor is bundled in the app, no downloads needed to start.
- Links that point outside the editor stay inside the app.
